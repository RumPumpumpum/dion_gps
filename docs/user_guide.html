디온 GPS

누구나 따라 하는 설치 & 사용 설명서
Android 앱

디온 GPS는 화면 가운데의 큰 버튼을 한 번 누르면 내 휴대폰 위치를 정해진 장소로 바꿔주는 앱입니다.

그림을 보면서 위에서부터 순서대로 따라 하시면 됩니다. 약 5분이면 끝납니다.

준비물

  • 안드로이드 휴대폰 (안드로이드 8.0 이상)
  • 전달받은 설치 파일 디온GPS.apk (카카오톡·문자·이메일 등으로 받은 파일)

앱 설치하기

1설치 파일 열기
  • 휴대폰에서 받은 디온GPS.apk 파일을 손가락으로 누릅니다.
  • 파일은 보통 내 파일 → 다운로드 폴더에 있습니다.
2"알 수 없는 앱" 설치 허용
  • 설치가 막히면서 안내 창이 뜨면 설정을 누릅니다.
  • 이 출처 허용 스위치를 오른쪽으로 켭니다(초록색).
  • 뒤로 가서 설치를 다시 누릅니다.
3보안 경고가 나오면
  • "안전하지 않은 앱" 같은 경고가 나오면 무시하고 설치를 누릅니다.
  • 스토어를 거치지 않은 앱이라 뜨는 정상 안내이니 안심하셔도 됩니다.
이 경고들은 나쁜 앱이라서가 아니라, 스토어(플레이스토어)를 통하지 않고 파일로 직접 설치할 때 항상 나오는 안내입니다. 걱정하지 말고 그대로 진행하세요.

위치 기능 켜기 (꼭 필요해요)

설치만 하면 아직 위치가 바뀌지 않습니다. 아래 설정을 한 번만 해두면 됩니다.

4개발자 옵션 켜기
  • 설정 → 휴대전화 정보 → 소프트웨어 정보로 들어갑니다.
  • 빌드번호를 7번 연속 빠르게 누릅니다.
  • "개발자가 되었습니다" 문구가 뜨면 완료입니다.
5디온 GPS를 위치 앱으로 지정
  • 설정 → 개발자 옵션으로 들어갑니다.
  • 모의 위치 앱 선택을 누릅니다.
  • 목록에서 디온 GPS를 고릅니다.
6권한 허용
  • 앱을 처음 열면 위치 권한을 물어봅니다 → 허용
  • 알림 권한을 물어보면 함께 허용합니다.
앱 안의 안내 버튼을 누르면 5번의 설정 화면으로 바로 이동합니다. 휴대폰 제조사에 따라 메뉴 이름이 조금 다를 수 있습니다.

사용 방법

가운데 큰 버튼한 번 누르면 정해진 위치로 바뀝니다(초록색). 다시 누르면 꺼집니다.
자동 종료시간을 정해두면(5분~1시간, 직접 입력도 가능) 그 시간 뒤 저절로 꺼집니다.
남은 시간자동으로 꺼질 때까지 남은 시간이 화면에 보입니다.
홈 화면 위젯위젯을 놓으면 앱을 열지 않고 홈 화면에서 바로 켜고 끌 수 있습니다.

잘 안 될 때

위치가 안 바뀌어요5번에서 디온 GPS가 선택됐는지 확인하고, 지도 앱을 껐다 켜 보세요.
목록에 디온 GPS가 없어요앱을 한 번 실행한 뒤 다시 "모의 위치 앱 선택"을 열어 보세요.
설치가 안 돼요2번의 "이 출처 허용"이 켜져 있는지 확인하세요.
