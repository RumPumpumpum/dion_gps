디온 GPS

Android Mock Location 앱 · 사용 설명서
Kotlin · Android

디온 GPS는 휴대폰의 위치를 지정된 고정 좌표로 표시해 주는 Android 앱입니다. 화면 중앙의 큰 원형 버튼 한 번으로 켜고 끌 수 있으며, 홈 화면 위젯과 자동 종료 타이머를 지원합니다.

테스트·개발·과제 목적의 위치 표시 확인용으로 제작되었습니다.

2. 주요 기능

① 위치 표시 켜기 / 끄기

  • 중앙의 큰 원형 버튼을 누르면 지정된 고정 위치로 전환됩니다.
  • 한 번 더 누르면 해제되어 원래 상태로 돌아갑니다.
  • 동작 중에는 버튼 주위에 펄스(맥동) 애니메이션과 초록색 상태 표시가 나타납니다.

② 자동 종료 타이머

  • 설정에서 자동 종료 시간을 선택할 수 있습니다: 5분 / 10분 / 15분 / 30분 / 1시간.
  • 목록 맨 아래 사용자 정의를 선택하면 원하는 분을 직접 입력할 수 있습니다.
  • 설정한 시간이 지나면 자동으로 종료됩니다.
  • 메인 화면과 위젯에 남은 시간이 실시간 카운트다운으로 표시됩니다.

③ 홈 화면 위젯

  • 앱을 열지 않고 홈 화면에서 탭 한 번으로 켜고 끌 수 있습니다.
  • 기본 크기는 1×1이며, 가로로 최대 4칸까지 늘릴 수 있습니다.
  • 상태에 따라 배경색이 바뀌고(켜짐: 초록 / 꺼짐: 회색), 자동 종료 남은 시간도 표시됩니다.
  • 메인 화면 하단의 "홈 화면에 위젯 추가" 버튼으로 바로 설치할 수 있습니다.

④ 백그라운드 유지 및 알림

  • 앱을 닫아도 동작이 유지되며, 상태 알림에서 바로 종료할 수 있습니다.

3. 설치 가이드

이 앱은 Play 스토어에 등록된 앱이 아니라 APK 파일을 직접 설치하는 방식입니다. 따라서 설치 과정에서 나타나는 보안 경고를 수동으로 허용해 주어야 합니다.

3-1. APK 파일 준비

  • Android Studio에서 Build → Build Bundle(s) / APK(s) → Build APK(s)로 빌드
  • 생성 위치: app\build\outputs\apk\debug\app-debug.apk
  • 이 APK 파일을 휴대폰으로 복사(USB, 클라우드, 메신저 등)

3-2. "출처를 알 수 없는 앱" 설치 허용

APK를 처음 실행하면 "이 출처의 앱은 설치할 수 없습니다" 경고가 나타납니다. 다음처럼 허용합니다.

  1. 경고 창에서 설정을 탭
  2. 이 출처 허용 / 알 수 없는 앱 설치 허용을 켬
  3. 뒤로 가서 설치를 다시 진행

경로 예시: 설정 → 앱 → 특별한 접근 → 알 수 없는 앱 설치 → (파일 관리자/브라우저) → 허용

3-3. Play Protect 경고 우회

설치·실행 시 "Play Protect가 이 앱을 인식하지 못했습니다" 또는 "안전하지 않은 앱" 경고가 나타날 수 있습니다. 직접 만든 앱이므로 아래처럼 진행합니다.

  1. 경고 창에서 자세히 → 무시하고 설치(또는 "확인 없이 설치")를 선택
  2. 필요 시 Play 스토어 → 프로필 → Play Protect → 설정에서 기기 보안 위협 검사를 일시적으로 꺼두면 경고가 줄어듭니다.
보안 경고는 스토어를 거치지 않은 앱이라 뜨는 정상적인 안내입니다. 본인이 만든 과제용 앱이므로 허용해도 됩니다. 설치가 끝난 뒤에는 Play Protect를 다시 켜 두는 것을 권장합니다.

3-4. (대안) USB 디버깅으로 바로 설치

  • 휴대폰: 설정 → 개발자 옵션 → USB 디버깅 켬
  • PC와 USB 연결 후 Android Studio에서 Run(▶) → 위 보안 경고 없이 바로 설치·실행

4. GPS 조작 앱 설정 (필수)

설치만으로는 동작하지 않습니다. Android의 모의 위치 기능은 개발자 옵션에서 이 앱을 지정해야 켜집니다.

  1. 개발자 옵션 활성화 — 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드 번호를 7회 연속 탭
  2. 모의 위치 앱 선택 — 설정 → 개발자 옵션 → 모의 위치 앱 선택 → 디온 GPS
  3. 위치 권한 허용 — 앱 최초 실행 시 위치 권한을 허용
  4. 알림 권한 허용 — Android 13 이상에서 상태 알림 표시용
앱 안의 안내 버튼을 누르면 개발자 옵션의 "모의 위치 앱 선택" 항목으로 바로 이동하도록 되어 있습니다. (기기·제조사에 따라 메뉴 이름이 다를 수 있습니다.)

5. 사용 순서

  1. 앱을 실행합니다.
  2. 중앙의 원형 버튼을 눌러 고정 위치로 전환합니다.
  3. 필요하면 자동 종료 시간을 설정합니다.
  4. 다시 버튼을 누르면 해제됩니다.
  5. 홈 화면 위젯을 추가하면 앱 없이도 빠르게 켜고 끌 수 있습니다.

6. 화면 구성 요약

중앙 원형 버튼메인 토글. 켜짐/꺼짐 상태를 색과 애니메이션으로 표시
상태 표시현재 동작 여부(조작 중 / 꺼짐)
자동 종료 버튼현재 설정값 표시(예: "자동 종료 : 15분"), 탭 시 설정 화면 이동
남은 시간자동 종료까지 남은 시간 카운트다운
하단 정보고정 주소·좌표, 위젯 추가 버튼
